# Privacy Policy for Strongholds Mastery

**Effective Date:** 03/11/2023
**Last Updated:** 30/08/2026

This policy describes how Strongholds Mastery gathers and manages user information
within Discord, aligned with the Data Protection Act 2018 and UK GDPR requirements.

## Information We Collect

The bot stores the minimum Discord data needed for its features, on the operator's
private server:

- **Discord user IDs and server IDs** — to associate users with features they opt
  into (vacation/absence tracking, party membership, self-assigned roles, language
  preference).
- **Role and channel IDs** — per-server configuration (welcome channel, ban/log
  channels, self-role setup).
- **Bot interaction records** — command usage needed to operate those features.
- Any supplementary data you voluntarily provide through commands.

## What We Do NOT Collect

- **Message content.** The bot does not request Discord's Message Content intent
  and cannot read messages in your server.
- **Presence data.** The bot does not request the Presence intent and does not
  track online status or activities.

The bot uses Discord's Server Members intent solely to post configured welcome
messages when a member joins and to display current member names in command
output. Member data received this way is used for display and is not persisted
beyond the IDs listed above.

## How We Use Information

We use the information we collect to operate, maintain, and provide the features
and functionality of the bot, as well as to communicate directly with you.

## Sharing of Information

Personal data is not sold or shared with any third party, except when you
authorize disclosure or legal obligations necessitate sharing.

## Data Security

Multiple protective measures safeguard your information, though no method of
transmission over the Internet, or method of electronic storage, is 100% secure.

## Data Retention and Deletion

Data is kept only while the associated feature entry exists. Removing the bot
from a server ends collection for that server. You have the right to access,
amend, and delete your personal data at any time by contacting us directly.

## Changes to This Policy

Updates will be announced by posting revised versions to this location.

## Contact Us

Reach out via the support server for inquiries regarding this policy.
