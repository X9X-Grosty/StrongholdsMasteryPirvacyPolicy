# Privacy Policy for Strongholds Mastery

**Effective Date:** 03/11/2023
**Last Updated:** 30/08/2026

This policy describes how Strongholds Mastery gathers and manages user information
within Discord, aligned with the Data Protection Act 2018 and UK GDPR requirements.

## Information We Collect

The bot stores the minimum Discord data needed for its features, on the
operator's own private server:

- **Discord user IDs** — only where a feature needs them: war-party membership,
  your language preference, and moderation audit entries.
- **Server, channel, and role IDs** — per-server configuration (welcome channel,
  ban/log channels, vacation channels, self-role setup).
- **In-game player names** — for vacation tracking and player notes; these are
  game identities, not Discord accounts.
- **Bot interaction records** — command usage needed to operate those features.
- Any supplementary data you voluntarily provide through commands.

## What We Do NOT Collect

- **Message content.** The bot does not request Discord's Message Content intent
  and cannot read messages in your server.
- **Presence data.** The bot does not request the Presence intent and does not
  track online status or activities.

The bot uses Discord's Server Members intent solely to post configured welcome
messages when a member joins and to display current member names in command
output. Member data received this way is used for display and is not persisted
beyond the IDs listed above.

## How We Use Information

We use the information we collect to operate, maintain, and provide the features
and functionality of the bot, as well as to communicate directly with you.

## Sharing of Information

Personal data is not sold or shared with any third party, except when you
authorize disclosure or legal obligations necessitate sharing.

## Data Security

Stored data is encrypted at rest, at both the database level and the file level,
and access to the server is restricted to the operator. As with any online
service, no method of transmission over the Internet, or method of electronic
storage, is 100% secure.

## Data Retention and Deletion

Data tied to a feature you opt into is retained while that feature entry remains
active, which may be longer than 30 days. Entries are deleted when you or a
server administrator remove them, when the bot leaves a server, or on request.

You have the right to access, amend, and delete your personal data at any time.
To request deletion, contact us through the support server (https://discord.gg/5eHFZybr6n)
or message the operator directly on Discord (ghxstinthesystem). Requests are
processed manually and honored promptly.

## Changes to This Policy

Updates will be announced by posting revised versions to this location.

## Contact Us

Reach out via the support server (https://discord.gg/5eHFZybr6n) or contact the
operator on Discord (ghxstinthesystem) for inquiries regarding this policy.
